01

Home Screen

Personalized starting point for daily AIMS work. Use it to surface assigned work, operational lists, charts, and quick access to the records that matter most.

Learning focus

Learn how the home screen supports a user-specific workflow; identify common dashboard/list content; use navigation efficiently; understand why results can differ by employee/security.

Practical checklist

  • Review assigned work and priority items
  • Use widgets/lists as navigation into operational records
  • Recognize that home-screen content can be user-specific
  • Troubleshoot visibility by checking filters, security and user settings

02

Equipment

The asset record is the center of equipment management: identification, location, manufacturer/model, risk, status, history, warranty and lifecycle information.

Learning focus

Understand the equipment record; locate key asset information; distinguish equipment-level data from standardized Data Manager values; connect equipment to maintenance history.

Practical checklist

  • Find an asset by tag or other identifiers
  • Review manufacturer, model, type, location, risk and status
  • Understand equipment documentation and history
  • Recognize how equipment records connect to work orders and PM schedules

03

Work Order

Work Orders track maintenance activity from preventive maintenance through repairs, including requests, assignments, labor, materials, notes and completion.

Learning focus

Follow the work-order lifecycle; understand common fields; assign/dispatch work; record labor/material/notes; complete and review maintenance history.

Practical checklist

  • Create or locate a work order
  • Review status, type, priority, requester and due information
  • Understand employee assignment and dispatch concepts
  • Apply labor, material and notes before completion

Import

The Import Tool processes user-populated Excel data and can import Equipment, PM Schedules, Work Orders, and Labor/Material lines. Existing Equipment and Work Orders can also be exported, edited and imported back.

Learning focus

Understand import scope and spreadsheet-driven processing; validate source data before processing; review errors carefully; test high-impact changes before production.

Practical checklist

  • Use the correct import template/data type
  • Validate required fields and standardized values
  • Review processing results and rejected rows
  • For mass changes, verify in test before production

11

Data Manager

Data Managers are AIMS Valid Entry Safeguards: standardized lists and defaults that improve enterprise-wide data consistency and reporting accuracy.

Learning focus

Understand standardized master data; recognize manufacturer/model and equipment-type governance; understand how defaults reduce repetitive entry; avoid duplicate/non-standard values.

Practical checklist

  • Search before creating a new standardized value
  • Understand parent/child relationships such as manufacturer/model
  • Review defaults and downstream impact before changing them
  • Treat merges and master-data edits as high-impact operations
